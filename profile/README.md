# CinePro Foundation

**The largest working open-source movie and TV show scraper ecosystem.**  
Personal use · TypeScript · OMSS-compliant

[![Docs](https://img.shields.io/badge/docs-CinePro.Mintlify.App-red?style=flat-square)](https://cinepro.mintlify.app)
[![Discussions](https://img.shields.io/badge/discussions-GitHub-blue?style=flat-square)](https://github.com/orgs/cinepro-org/discussions)

</div>

---

CinePro is a collection of open-source tools for scraping and playing movies and TV shows. At its core is an [OMSS-compliant](https://github.com/omss-spec/omss-spec) TypeScript backend that resolves stream sources from multiple providers using TMDB metadata.

> [!CAUTION]
> All CinePro projects are for **personal and non-commercial use only.**  
> Users are responsible for complying with applicable laws and the terms of service of streaming sources.

## Projects

| Repository | Description | Status |
|---|---|---|
| [core](https://github.com/cinepro-org/core) | OMSS-compliant TypeScript scraper backend | 🟢 Alpha |
| [frontend](https://github.com/cinepro-org/frontend) | React web interface and video player | 🟡 Beta |
| [CineHome-backend](https://github.com/cinepro-org/CineHome-backend) | Automated movie/episode downloader for home servers | 🟡 Beta |
| [CineHome-frontend](https://github.com/cinepro-org/CineHome-frontend) | Web UI for CineHome | 🟡 Beta |
| [backend](https://github.com/cinepro-org/backend) | Original JavaScript scraper _(archived)_ | 🔴 Archived |
