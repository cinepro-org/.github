CinePro is a collection of open-source tools for scraping and playing movies and TV shows. At its core is an [OMSS-compliant](https://github.com/omss-spec/omss-spec) TypeScript backend that resolves stream sources from multiple providers using TMDB metadata.

> [!NOTE]
> All CinePro projects are for **personal and non-commercial use only.**
> While we don't have issues with people hosting it publicly, we don't suggest doing that.
> Users are responsible for complying with applicable laws and the terms of service of streaming sources.
